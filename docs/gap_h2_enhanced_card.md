# GAP H2 增强版 策略卡（C0+重置 基底 + 分批止盈 / 跟踪止损）

> 这是一支**拟采用**的新策略，**不覆盖原版**。原版 C0 策略卡保留在 `docs/gap_h2_strategy_card.html` 作对照。
>
> **边界（重要）**：本卡「五、持仓管理」的分批止盈 / 跟踪止损 / 低2反转，**只用于回测与复盘，不进生产扫描**。生产（真实每日扫描）仍只做原版卡四类的"当天提醒 + 标注"。
>
> **本卡 = C0 原版信号逻辑 + 新高重置 + 新出场方案。** 相对原版 C0：信号逻辑只多「新高重置」一条；**出场整体替换**为 2R 半仓 + 跟踪 + 低2 反转（原测量止盈废弃）。真缺口 / 40-2 窗口 / 缺口地板止损 全部维持原版，未改动。
>
> **两把尺子（止损相关，避免混淆）：**
> - **缺口地板** = 前 60 根最高**高**（突破前的"天花板"，突破后变支撑；初始止损 + 触发前闸门）
> - **回调低点** = 信号K（第二次回调 LHLL）最低价（首次过突破高点后，剩半仓止损移到这里；**在入场价下方、不锁利**，但比缺口地板紧得多）
>
> 位置（有效形态下）：**回调低点 > 缺口地板**。触发后若回落，先碰回调低点（硬底线），缺口地板只在触发前当地基闸门。
>
> 用词约定：「**前高 / 突破腿最高点（SH）**」专指突破以来的绝对高点；「**前根K高点**」指前一根 K 的最高价。两者不是一回事。

## 五、持仓管理（拟采用：分批止盈 + 跟踪止损，待回测）

| # | 规矩 | 现在怎么设 | 大白话 / 调它会怎样 |
|---|------|-----------|-------------------|
| 1 | 【新】2R 半仓止盈 | 入场后 high ≥ 2R → 平半仓（按 2R 限价） | 先落袋一半利润，剩半仓去博更大空间。 |
| 2 | 【新】跟踪启动（硬底线） | 剩半仓首次 high > 突破腿最高点（SH）时，止损一次性移到「信号K最低价」 | 价格证明自己（吃掉突破高点）后，把剩半仓止损收紧到信号K低点（固定，不随新高抬升；**在入场下方，不锁利**但比地板紧得多）。 |
| 3 | 【新】未过 SH 前 | 剩半仓止损维持缺口地板 | 还没证明自己前，用初始地板扛着。 |
| 4 | 【新】低2 反转出场 | 创新高后计数 LL→HH→LL，完成即离场；每次新高重置计数 | 新高后若走出"更低低→更高高→更低低"反转结构 = 趋势翻面，剩半仓离场。 |
| 5 | 优先级 | 规则2 止损是硬底线（优先），低2 反转是底线之上主动离场 | 不冲突：底线兜底，反转提前下车。 |
| 6 | 原测量止盈废弃 | 不再用 2×地板 − 前摆低 | 统一由上面 2R + 跟踪方案取代。 |

### 相对原版（C0）的改动（回测对照清单）
1. **「二、回调过程」第 5 条（新增）**：新高重置 —— 唯一改动信号逻辑的一条
2. **「四、开仓计划」第 3 条（新增）**：2R 线定义 —— 为分批止盈服务
3. **「五、持仓管理」（整体新增）**：分批止盈 + 跟踪 + 低2 反转，取代原测量止盈
- 真缺口 / 40-2 窗口 / 缺口地板止损 / 测量止盈 **全部维持原版 C0**，未改动（前几版试过的实体缺口 / 20-3 / 紧止损 / 实体版参考线均已回测证伪或放弃）

### 怎么用
说「**"五、持仓管理"第 2 条改成 ××**」或「**"二、回调过程"第 5 条**」，按大类标题 + 序号定位，先讲清改完信号变多还是变少、要不要连带动回测，再动手。

### 六类含义
- 一背景（地基）· 二回调（两试 + 缺口撑住 + 新高重置）· 三信号（排高潮 + 看成色）· 四开仓（买卖 + 风险定义）· 五持仓（拟采用新出场）· 六其他（打分展示）
- 一 / 二 / 三 / 四 = **动一条就改信号**；五 = **拟采用新出场（回测验证）**；六 = **打分展示，只改显示不改信号**
