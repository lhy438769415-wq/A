# gap_h2_enhanced 回测 — 样本示例（确认格式用）

> 用现有回测引擎（原版 `GapH2Strategy`）在真实历史日线数据上跑前 120 只股票，捞出 1 个止盈 + 1 个止损作为样本，确认你要的「样本」长什么样。
> 注：以下字段来自回测引擎当前返回的交易记录字典。可以看到它**没有把 SL/TP 价格本身存进记录**（只存了入场价和出场价，止盈出场价=TP、止损出场价=SL）。正式做 enhanced 回测时我会把 `sl_price` / `tp_price` 也写进每条记录，让样本自包含。

## 样本 A — 止盈（TP 触发）

| 字段 | 值 | 大白话 |
|---|---|---|
| code | sz.000007 | 标的 |
| signal_date | 2024-10-16 | 信号 K（第二次回调低点）出现的那天 |
| entry_date | 2024-10-17 | 次日挂 Buy Stop 触发入场那天 |
| entry_price | 6.83 | 实际入场价（涨过信号 K 最高价成交）|
| exit_price | 8.54 | 出场价 —— 这里 = 止盈目标价 TP |
| reason | take_profit | 涨到了目标价，止盈离场 |
| rr | +3.56 | 这笔赚了 3.56 个 R（风险倍数）|
| pb_bars | 6 | 突破后第 6 根完成两试 |
| sig_quality | 0.41 | 信号 K 收盘位置中等（偏下）|

## 样本 B — 止损（SL 触发）

| 字段 | 值 | 大白话 |
|---|---|---|
| code | sz.000001 | 标的 |
| signal_date | 2024-10-16 | 信号 K 出现那天 |
| entry_date | 2024-10-17 | 次日触发入场 |
| entry_price | 11.565 | 实际入场价 |
| exit_price | 10.741 | 出场价 —— 这里 = 止损价 SL（跌破了缺口地板/回调低点）|
| reason | stop_loss | 跌破止损线，认赔离场 |
| rr | -1.00 | 这笔亏了 1 个 R（刚好打止损）|
| pb_bars | 6 | 突破后第 6 根完成两试 |
| sig_quality | 0.71 | 信号 K 收盘位置较高（偏强）|

## 我对你要求的理解（请确认）

1. **任务对象**：给「gap_h2_enhanced」这支新策略做**历史数据回测**。但 enhanced 现在只有策略卡、还没写成代码，所以正式任务是：先把卡上的三处改动（实体缺口/新高重置/回调低点止损）做成**参数化变体**，再复用这套回测引擎跑同数据集出结果。
2. **样本的意义**：在正式全量回测前，先跑一个小样本，给你看「一个止盈长什么样、一个止损长什么样」，确认记录字段、出场原因、R 值口径正是你要的，再扩到全市场。
3. **一个待你拍板的点**：当前引擎记录里**不含 SL/TP 本身**（只含入场/出场 + 原因 + R）。我建议在 enhanced 回测记录里**补上 `sl_price` 和 `tp_price`** 两个字段，这样每个样本能一眼看到「入场/止损/止盈/实际出场」四价齐全。是否同意？
