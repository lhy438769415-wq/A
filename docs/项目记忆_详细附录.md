## A. 策略卡配图 · 完整规范（2026-09-27 定稿）

**风格来源**：用户原话「你这个示意图的风格就是我想要的策略卡配图的风格」——即 `show_widget` 那一套，此后勿再换风格。

### A1. 通用规范
- `viewBox="0 0 680 H"`（宽度恒 680）+ `width="100%"`。
- **背景透明**（底色由宿主卡片给）。
- **纯扁平**：禁渐变、禁阴影、禁发光、禁 3D。
- 预置类 `class="t" / "ts" / "th"`；颜色走 CSS 变量（浅色 50 填充 + 600 描边）。
- **描边一律 0.5px**。
- 字重只有 400 / 500（无 bold）；字号 ≥ 11px（标题 14 / 正文 13 / 小字 12）。
- 单图 ≤ 2 色系；无 emoji；sentence case（句首大写）。
- 安全区 x ∈ [40, 640]。
- **铁律：解释文字写在响应正文里，图内只放标签**（不往图里堆段落）。

### A2. 必须内嵌，不能 `<img src>`（实测踩坑）
图内文字走 `currentColor` 继承外层字色。`<img>` / `<object>` 里的 SVG 是**独立文档**，`currentColor` 退化成默认**黑色**，在卡片暗底（#1e1e1e / 图底 #232323）上直接看不见。

正确做法（内嵌 + 容器样式）：
```css
.fig { background:#232323; border:1px solid #3a3a3a; border-radius:6px; padding:16px 18px 12px }
.fig svg { color:#c9c9c9 }
.figcap { /* 图注 */ }
```

## B. 缺口上沿定义 + GAP H2 图表标注（实现对照）

### B1. 缺口上沿统一定义
**定义**：`上沿 = min(初始上沿, 回调最低价)`
- **初始上沿** = **突破 K 自身的 low**（即跳空缺口真空区的上边缘 / 天花板）。
- **回调最低价** = 突破 K **之后**到**信号 K（含信号 K）**区间的最低 low。
- 取小 → 回调砸得越低，上沿被压得越低（缺口"被压缩缩小"）→ 直接影响 `gap_size_pct` 与评级分。

⚠️ **措辞陷阱**：旧记忆写成"首次出现缺口后续 K 线的最低点"，字面读起来像**排除突破 K**，不准确。必须显式写成 `min(初始上沿, 回调最低价)`。

**勿改回 `high[b]`（突破 K 高点）**：那是 `4c351cd` 多缺口并行重构的回归（上沿被错写成突破高点），`1a82563` 已修回。

**定位与复核**：2026-08-12 定位；2026-09-27 用户纠偏措辞 + 全家族实测 13/13 复核（sz.000906 / sz.002011 / sh.600519 / sz.002102 / sz.002214 / sz.002357 等）全部 MATCH。

**三家族实现（写法不同、效果一致）**：
| 家族 | 代码位置 | 写法 |
|---|---|---|
| GAP_H2 | `gap_h2_strategy.py:246` → `:280` | `cummin_low = np.minimum.accumulate(sub_low)`，`sub = df.iloc[b:]`（**起点含突破 K**）→ `top_series = cummin_low[li]` |
| GAP_PINBAR | `gap_pinbar_strategy.py:250` / `:281` | 同上同构 |
| STRUCT_GAP | `structural_gap_strategy.py:239` → `:332` | `_group_min_low`（groupby(cumsum).expanding().min()）→ `struct_gap_top_exact = _group_min_low.shift(1)`，**看似排除信号 K**；但该家族信号条件含 `lower_low_stopped`（`:253` `low >= low.shift(1)`），信号 K 低点必非新低 → 与"含信号 K"**数值等价** |

另：`:272` 的 TP 侧 `_effective_gap_top = min(_group_min_low.shift(1), _breakout_low)` 就是把本公式显式写出来（含突破 K 低点保底）。

### B2. GAP H2 图表 BO / H1 / SL1 三铁律
代码在 `core/strategies/structural_gap_strategy.py` 的 `_annotate_gap_strategy`，「标注 3c GAP_H2 状态机节点」段。经 2026-09-27 用户三轮纠偏后定稿，**勿再反复**。

- **BO = 发起这笔缺口的突破 K**：用 `bars_since_breakout_h2` 反推（`_bo_pos2 = _sig_pos2 - bsb`）。
  **不是**"信号前最后一根突破 K"——那会选到后出现的次级突破 / 跟随 K。
  语义对应策略卡第一条：一根 HH+HL 且 `low > 过去60根最高价` 的 K 线。
  仅当策略列缺失时才兜底回退到"信号前最后一根突破 K"。
- **SL1 = 回调低点** = BO 之后（**不含 BO 自身**）区间的最低 `low`，即 `_seg2.iloc[1:]['low'].idxmin()`。
  **不是**缺口地板（Gap Floor），**不是** BO 自身低点。
  注意策略列 `gap_h2_top_exact` **含** BO 自身，若 BO 低点最低会误指 BO → 绘图须自行排除首根。
- **箭头 x 坐标一律取 K 线正中**（`_x`），不再写 `_x + 0.5`（偏右半根会被误看成指向下一根）。
- H1 = BO 之后首腿回调（首根 LHLL）后的首根 HH。
- H2 标签仍只在 `anchor_signal_date` / `exit_mark` 显式锚定（回测 / 成册）时绘制，**生产推送不画**。

## C. MTR 风险单位 R 退化 · 实测记录

**机理**：`risk = entry_ref − sl_price`，其中 `entry_ref = 信号K最高价`、`sl_price = min(L1, TL) − 0.01`。
当**信号 K 整根位于结构低点之下**时，两者几乎重合 → `risk` 退化为浮点残渣（1e-5 量级）→ 净 R 被放大数千倍。

**实测案例**：
| 标的 / 结构 | 信号K最高价 | sl | risk | net_R |
|---|---|---|---|---|
| 002347，TL=2023-10-12（OLD） | `4.8167` | `4.8167` | `0.0000` | **−2001.744** |
| 600867，TL=2024-06-19（S2） | `7.9182` | `7.9178` | `0.000358`（占价 0.0045%） | **−295.634** |

**全市场污染量（净 R < −3 计）**：
- 严格口径：**OLD 31 笔 / −2,834R**（占其净 R 的 8.8%）、S2 17 / −986、S3 4 / −24、NEW_B **0**。
- 宽松口径：S2 **52 笔 / −32,098,280,446,721R（约 32 万亿）**（原始 EV 显示 −1,162,981,175.38 R）、S3 29 / −2,852。

**为什么影响生产**：OLD 组走的就是生产函数 `_find_signal_bar` → **生产推送会产出"入场价与止损价只差 0.001%"的不可交易信号**。

**建议护栏（未实施）**：`entry_ref − sl ≥ max(0.5 × ATR14, 价格 × 1%)`，或要求信号K最高价 > `min(L1, TL)`。

**读回测 EV 时的纪律**：先查是否已剔除退化样本，否则 OLD / S2 会被系统性压低。

## D. signal_archive 重复归档与回测污染 · 详细记录

- **根因**：`archive.py:32` 把 strategy / timeframe 拼进 signal_id → 改名 / 加字段即换 key，PRIMARY KEY 去重被打穿。
- **三代 signal_id 格式**：
  1. `{code}_STRUCTURAL_GAP_{YYYY-MM-DD}`（≤ 05-22，无 timeframe、旧策略名）
  2. `{code}_STRATEGY_STRUCTURAL_GAP_{YYYY-MM-DD}`（06-05 ~ 08-01，策略改名加前缀）
  3. `{code}_{strategy}_{timeframe}_{YYYY-MM-DD}`（08-01 ~，当前）

- **回测污染生产表**：周线 3,154 行中 **2,611 行是 `BT_` 前缀回测行**（2026-05-31 批量写入），生产行仅 543 → `status` 分布被回测主导（WIN 2,748），**任何按 status 的统计不可信**。674 行 signal_date 为 bar 序号。
