## 0. 总体定位（先说对的）

用 skill 的 UI_Category 映射，本项目的正确类目是 **"SaaS Dashboard / Data-Dense（数据密集仪表盘）"** 叠加 **"Fintech-Banking-Dark（暗色 + 信任蓝）"**。原型在这两点上做对了：

- ✅ 暗色 HSL 变量 + 电光蓝主色，直接套 TSP 且 **A 股红涨绿跌**（CSS 注释 `#F04438 红涨`）——无需改色，方向正确。
- ✅ 数字一律等宽（`tabular-nums`），KPI / 价格 / 收益对比一目了然——Fintech 类目核心要求。
- ✅ **状态/方向同时用「颜色 + 文字」**（活跃/已建仓/前提不存在 + 多/空），满足可达性「不单纯靠颜色传意」红线。
- ✅ 每页底部「字段来源 / 数据溯源」折叠表——正面回应了你对「没有数据来源的字段」的关切，是这份原型最大的亮点。
- ✅ 空状态齐备（待建仓为空、缺失标的为空），非空白死屏。
- ✅ K 线 SVG 预设 `width/height`，无布局抖动（Content-Jumping 红线规避）。

下面只挑问题，按维度列。

## 2. 导航（Navigation）

| # | 问题 | 行号 | 严重度 | 说明（对照 UX 指南） |
|:--|:--|:--|:--|:--|
| 2.1 | **导航用 `<div onclick>` 而非 `<a>/<button>`** | 180-187 | 🟠 P1 | UX#42 语义化：无 `<nav>/<aside>/<main>` 地标，屏幕阅读器难导航；键盘不可达（Tab 无法聚焦）。原型可接受，但 v2 正式版须用原生按钮/链接。 |
| 2.2 | **无焦点环（`:focus-visible`）** | 全局 CSS | 🔴 P0 | UX#28（High）：全原型没有任何 `:focus-visible` 样式。键盘用户（你后续可能用键盘快速翻信号）完全看不到当前焦点在哪。这是可达性硬伤。 |
| 2.3 | **无深链 / 无历史栈** | JS 全篇 | 🟡 P2 | UX#4/#5：切换页面不动 URL，浏览器「后退」失效、无法分享「某页」链接。作为 localhost 自用工具优先级低，但 v2 建议用 hash 路由（`#/signals?tf=weekly`）以兼顾客服/复盘截图溯源。 |

## 7. 视觉系统一致性（Design System）

整体令牌统一，仅一处需裁齐：

- **圆角/边框**：卡片 12px、KPI 10px、按钮 8px、pill 999px——梯度合理。
- **阴影**：全原型几乎无 `box-shadow`，靠 1px 边框分隔（TSP 风，正确，避免「过度阴影」反模式 UX#1）。
- **动画时长**：抽屉 200ms、卡片 border 150ms——落在 UX#8 推荐 150–300ms 区间内，合格。
- ⚠️ **一处不一致**：`--warning` 定义了但未使用；`--danger` 等同 `--bull`。无害，但正式设计令牌表应删 `--warning` 或赋予用途（如「待建仓」黄标）。

## 8. 优先级修复清单（按开工顺序）

**🔴 P0 — 进阶段 1 前必须改（直接在原型上修，再转 React）：**
1. 策略名对齐注册表：`AIL`→`AWIL`，`GAP H1`→对齐 `STRUCTURAL_GAP` 的 `display_name`；下拉/回测/STRATS/卡片全部统一，禁止中文花名硬编码。
2. 加全局 `:focus-visible` 焦点环（键盘可达性硬伤）。
3. 周线下拉做成**真能交互**的最小版（mock 演示「截至该周仍存活」切换效果），消除死控件、落实你的硬约束。

**🟠 P1 — 阶段 1 定稿前：**
4. 状态筛选做「中文展示 ↔ 库值」映射层（不直传中文）。
5. 去掉两个假可点 KPI 的 `cursor:pointer`（或给它们指下钻）。
6. 图标按钮补 `aria-label`；导航换原生 `<button>`/`<nav>` 语义。
7. 信号中心加「缺口存活」状态列；抽屉大图标注入场价/失效价水平线。
8. 预留骨架屏/加载态（为真实 API + SSE 扫描进度铺路）。
9. 「添加分组」改用内联输入，不用 `prompt()`。

**🟡 P2 — 阶段 2 考虑：**
10. KPI 行响应式塌缩；侧栏可收起。
11. 「移除分组」删选中项 + 确认；按钮 loading/disabled 态。
12. `prefers-reduced-motion`；搜索框 `aria-label`；小字提亮对比度。
13. hash 路由（深链 + 后退）。
14. 信号中心明示「不显示任何字母评级」。

## 10. 一句话结论

原型的**工程骨架与视觉方向是对的**（暗色专业、红涨绿跌、数据溯源表是亮点），但在你最在意的「**字段无来源**」上仍有两处硬伤（`AIL`/`GAP H1` 命名不符注册表），且违反了你定的「**所有控件可交互**」——**周线下拉是死控件、核心的「截至该周仍存活」口径完全没实现**。P0 三条不修，转 React 后会把错误固化进正式版。建议先在我上面标 P0 的 3 处改完原型，再进阶段 1。
