## 六、结论

- **样本量**：C0 原版全历史 3629 笔信号 / 2219 笔结案；C4 完整增强 1726 笔信号 / 1080 笔结案。
- **期望值 EV（单笔 R）**：C0 = +0.0915，C4 = -0.1247（原版更优）。
- **胜率**：C0 = 41.6%，C4 = 19.0%。
- **盈亏比**：C0 = 1.1539849636056512，C4 = 0.8482367203625646。
- **最大回撤（R）**：C0 = -248.62，C4 = -258.63。

### C0 原版 vs C0+重置(纯)（问题1：仅加新高重置，其余与 C0 一致）
> **关键结论（已修正）**：在 C0（真缺口）基础上**单独加新高重置，单笔期望值 EV 完全不变（+0.0915）**。重置不是"免费提升"，而是一次"密度换平滑"的取舍——它把"突破后创新高又下来的假 H2"识别出来并剔除，剩下的单子平均盈利更高（+1.896 vs +1.650），但胜率更低（38.1% vs 41.6%），两者恰好抵消。

- 信号数：C0 = 3629，C0+重置 = 2344（重置过滤 1285 笔，占 C0 的 35.4%）→ 信号密度大降
- EV（单笔R）：C0 = +0.0915，C0+重置 = +0.0915（**持平，并非更优**）
- 胜率：C0 = 41.6%，C0+重置 = 38.1%（降 3.5 个点）
- 盈亏比：C0 = 1.15，C0+重置 = 1.15（不变）
- 平均盈R：C0 = +1.650，C0+重置 = +1.896（升）；平均亏R：C0 = -1.016，C0+重置 = -1.017（持平）
- 累计净R：C0 = +203.0，C0+重置 = +137.5（因信号少了，总利润下降）
- 最大回撤：C0 = -248.62，C0+重置 = -197.90（**回撤更小、曲线更平滑**）；最大连亏 33 → 30

**取舍判断**：重置在纯 C0 上不改单笔质量，只减少交易并平滑曲线。是否采纳取决于你更看重"信号多、利润池大"还是"更少的单子、更稳的回撤"。**注意**：此前"新高重置是唯一单步正向改进"的说法是**基于实体缺口(C1→C2)语境**得出的——在实体缺口（放宽入口、混入低质量信号）下重置能滤掉渣单所以显正；在真缺口(C0)语境下重置对 EV 中性。重置的价值高度依赖上下文，不能一概而论。

### 回测方法一致性校验（问题2）
> **结论：两种方法对 C0 的结论逐位一致，用户怀疑的"方法不同"不成立。**

- 实测交叉核对：直接运行项目原装 `archive/tools/backtest_gap_h2.py`（其默认 `limit=1500`）得到 C0 日线 = **胜率 41.55%、EV +0.0915、已结案 2219、总信号 3629**；本对比框架（默认 `limit=None`）得到 C0 = **胜率 41.6%、EV +0.0915、已结案 2219、总信号 3629**。两者仅四舍五入差异，完全一致。
- **根因（已查清）**：`daily_bars` 全库仅覆盖 **2023-01-03 ~ 2026-09-18（约 3.7 年）**。原装工具 `tail(1500)`（≈6 年）因库比 1500 根更短而**从未真正截断**，所以"原方法(1500)"与"本框架(全历史)"用的数据窗口本就一模一样——并非两种方法各自独立、恰好凑巧相同，而是数据库长度决定了两者必然相同。
- 因此我**未再**用本框架额外跑 `limit=1500` 版本：在 3.7 年库上它与 `limit=None` 输出相同，属冗余。
- ⚠️ **重要前提**：所谓"全历史回测"实际只是 2023–2026 这一小段单一行情（含 2024 年急涨、2025 年结构市等特定 regime）。样本约 2200 笔结案，但**跨牛熊/跨多年周期的稳健性并未验证**，对策略 edge 的置信度应打折。
