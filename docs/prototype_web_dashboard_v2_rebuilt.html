关于本原型

这是按「纠正后地基」重建的版式确认稿：以 6 步闭环为脊、顶栏常驻同步/扫描、信号→内嵌 TV 精筛、策略从注册表动态读。所有按钮均可交互（含顶栏同步/扫描的模拟进度与终止）。原型数据为示意，正式版接 FastAPI 后端（复用现有 data_provider / scan_engine，经 SSE 报进度）。
