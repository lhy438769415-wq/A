## 2. 主线 B：GUI 不显 000906 的连锁故障修复

### 2.1 现象
用户跑 GUI 日线扫描，浙商中拓（`sz.000906`，深圳股，前缀 `sz` 非 `sh`）没出现在"今日信号"，但 Discord 已推送。

### 2.2 根因（两层，缺一不可）
1. **主因=GUI 白名单整条过滤**：主线 A 的 scanner `_tag` 把策略名写成 `STRATEGY_GAP_H2#2026-09-02`（带缺口诞生日尾巴）。GUI `_VALID_KEYS`（6 个干净注册名）与 `_STRAT_NORM_SQL` 不剥 `#` → 该信号在所有查询（列表/日期/计数/详情）被 `IN (白名单)` 排除 → **任何日期都看不到**。Discord 不经此过滤故正常。
2. **次因=信号日标错**：同段 `_tag` 把 `signal_date` 写成缺口诞生日（9/2），而非触发日（9/24）。即便修白名单，默认视图看最新日 9/24 也错过。

### 2.3 早期方案为何被否
最早想"改 GUI 白名单 + 删覆盖两行 + 清库"（A+B+C）。读全链后发现两暗坑且动 GUI 风险高：

## 4. 已验证的关键事实（策略研究硬基础）

### 4.1 缺口上沿统一公式（用户 09-27 纠偏、13/13 信号实测 MATCH）
**上沿 = `min(初始上沿, 回调最低价)`**
- 初始上沿 = **突破K自身的 low**（`low[b]`）——缺口上边缘/天花板。
- 回调最低价 = 突破K**之后**到信号K（含信号K）区间的最低 low。
- **勿改回 `high[b]`**（那是 `4c351cd` 多缺口重构前的回归写法）。
- 三家族代码写法不同、效果一致：GAP_H2 `gap_h2_strategy.py:246,280`（`cummin_low` 起点含 b）；GAP_PINBAR `:250,281`；STRUCT_GAP `structural_gap_strategy.py:239,332`（`_group_min_low.shift(1)` 因信号条件 `lower_low_stopped` 数值等价）。

### 4.2 `1e-3` 容差是故意设计，勿删（2026-09-26 用户纠偏）
缺口家族突破/存活判定写 `low > gap_floor_raw - 1e-3`。作用=让"低点刚好顶到/微破阻力"的突破不被浮点噪声误杀。删除属未验证行为变更，会让合法突破被漏掉。若要动须先全家族回测重验。

### 4.3 GAP H2 图表 BO/H1/SL1 三铁律（2026-09-27 用户三轮纠偏定稿）
- **BO** = 发起这笔缺口的突破 K（`bars_since_breakout_h2` 反推 `_bo_pos2 = _sig_pos2 - bsb`），非"信号前最后一根突破 K"。
- **SL1** = 回调低点（BO 之后**不含 BO 自身**区间的最低 low），非缺口地板、非 BO 自身低点（绘图须排除首根）。
- 箭头 x 坐标一律取 K 线正中（不再 `+0.5` 偏右）。
- 代码段：`core/strategies/structural_gap_strategy.py` 的 `_annotate_gap_strategy`「标注 3c GAP_H2 状态机节点」。
- H2 标签只在 `anchor_signal_date`/`exit_mark` 显式锚定时绘制，生产推送不画。

### 4.4 回测方法论提醒
- 本项目回测的 FIFO 满仓模型会系统性虚高胜率/收益，**对外汇报必须同时给"信号级诚实边缘"**（全跟、每笔独立），否则误导。
- 回测脚本须直接调用生产策略（单一事实来源），不得自带旧逻辑副本。

### 4.5 策略卡配图风格（用户 09-27 认可，勿换）
`show_widget` 那套 SVG 规范：viewBox `0 0 680 H` + 透明背景 + 纯扁平 + `class="t|ts|th"` + CSS 变量（浅色 50 填充/600 描边）+ 0.5px 描边 + 字重仅 400/500 + 无 emoji + sentence case + 图内只放标签、解释文字在正文。**必须内嵌 SVG 不用 `<img>`**（`<img>` 里 `currentColor` 退化成黑，暗底卡片上不可见）。
