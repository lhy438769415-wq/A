## 零、系统第一性（本次对话锚定的最高优先级）

> **本系统第一性 = 在每个交易日，把"可据此行动"的可信信号情报，可靠地交到人手上。**
> 系统定位"人机协作、只推信号不下单"——它**不下单、不做最终决策**，人据此下单、承担盈亏。
> 因此系统全部价值 = **信号可信 × 交付可靠**。

"可信"与"可靠"正好落在三个支柱上，它们是**地基（substrate）**，上层一切（策略识别 → AI 审计 → 推送 → 工程整洁）都建在地基之上：

| 支柱 | 含义 | 为什么是第一性 |
|---|---|---|
| **高可用** | 每天都能跑、不崩、不静默死 | 跑不起来 → 人收不到信号 → 系统归零 |
| **数据完整性** | 不缺行、不丢股票、无空洞 | 缺数据 → 漏机会 或 指标失真 |
| **数据准确性** | 价格对、异常被拦 | 错价 → 假信号 → 人亏真钱 |

**推论（纠正此前优先级偏差）**：原 P1 旗舰项"AI 跳过名单不一致"属于 **AI 审计层的一致性瑕疵**；而 AI 审计层本身只是"信号质量"这一**上层**关注点。把它当旗舰是看错了层级（当时看的是"代码一致性优雅"，不是"系统本质"）。**地基（三支柱）才是第一性，上层是装修。**

本次"真实数据库体检"（见第六节）证实：地基目前**基本健康**（integrity_check OK、0 NULL/重复/未来日期、流动性股票连续无洞）。**数据准确性经严格逻辑校验（high<low / 非正价 / 非正量 / 开收越界）为 0 处不可能值 → 实际健康**，此前"11 根坏 tick"的松判已被推翻（详见第四节 + 用户纠正）：11 根 `high>3×low` 中 1 根是已证合法的 IPO 首日（无涨跌停），其余 10 根需结合**事件/上市日期**复核（可能是重组复牌/重新上市无涨跌停日，未必是脏数据）。紧邻第一性的真问题只剩 **停牌边界对指标的潜在扰动（④b）** 与 **补一张事件日期表以正确分类异常 bar（④）**。
