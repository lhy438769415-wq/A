一笔交易的全程：价格越过缺口地板 5.90（前 60 根最高高）留缺口 → 两腿回调至 6.14 → 信号K高点 6.20 突破入场，初始止损放地板 5.90（R = 0.30）→ 价格先破 SH 6.64（突破腿最高点），剩半仓止损上移到信号K最低价 6.14 → 继续涨过 2R 6.80 平掉半仓 → 末尾走出「更低低→更高高→更低低」的低2 反转结构，剩半仓离场。
两把尺子（止损相关，避免混淆）：
· 缺口地板 = 前 60 根最高高（突破前"天花板"，突破后变支撑；初始止损 + 触发前闸门）
· 回调低点 = 信号K（第二次回调 LHLL）最低价（首次过突破高点后，剩半仓止损移到这里；在入场下方、不锁利，但比缺口地板紧得多）
位置：回调低点 > 缺口地板。触发后若回落，先碰回调低点（硬底线），缺口地板只在触发前当地基闸门。
用词约定：「前高 / 突破腿最高点（SH）」专指突破以来的绝对高点；「前根K高点」指前一根 K 的最高价。两者不是一回事。

一、背景判断 地基：趋势 + 真缺口
1突破周期看前 60 根价格越过前 60 根最高点才认定有趋势背景。
2缺口认定：真缺口突破K最低价 > 前 60 根最高高维持原版：必须是真跳空，缺口地板 = 前 60 根最高高。不放宽。
二、回调过程 两试 + 缺口撑住 + 新高重置
1回调最长等最多 40 根维持原版窗口。
2回调最短隔至少 2 根维持原版。
3地板不破回调全程不破缺口地板（前60根最高高）回调途中任一根最低价不得跌破；破了 = 支撑失效，信号撤掉。
4空头两试失败先跌 → 涨破前根K高点 → 再跌H2 核心形态：第二腿完成那根就是信号 K。中间"更高高"指涨过前一根 K 高点（非趋势高点）。
5【新】新高重置等 H2 期间创新高则推倒重来任一根 high 刷新前高（SH） → ①清空 H1/H2 计数 ②该新高设为新前高 ③从零重新找 H1。防"新高后那次其实是新趋势 H1"被误当 H2。
三、信号判断 排除高潮、看信号当根成色
1涨太猛不追信号前没先冲到目标已一口气涨到目标价 = 高潮释放，再进就晚了，作废。
2信号当根长相收盘越靠上越好信号 K 收盘位置高 = 多头控盘。只影响打分，不决定出不出。
四、开仓计划 买点 / 初始止损 / 风险定义
1买点突破信号高点才买次日挂 Buy Stop，涨过信号 K 最高价才成交，不提前追。
2初始止损破缺口地板就跑（前60根最高高）初始全仓止损 = 缺口地板。
3风险与 2R 线R = 入场 − 地板；2R 线 = 入场 + 2R2R 是后面"半仓止盈"的触发线（见五类）。
五、持仓管理 拟采用：分批止盈 + 跟踪止损，待回测
1【新】2R 半仓止盈入场后 high ≥ 2R → 平半仓（按 2R 限价）先落袋一半利润，剩半仓去博更大空间。
2【新】跟踪启动（硬底线）剩半仓首次 high > SH 时，止损移「信号K最低价」价格证明自己（吃掉突破高点）后，把剩半仓止损收紧到信号K低点（固定，不随新高抬升；在入场下方、不锁利但比地板紧得多）。
3【新】未过 SH 前剩半仓止损维持缺口地板还没证明自己前，用初始地板扛着。
4【新】低2 反转出场创新高后计数 LL→HH→LL，完成即离场；每次新高重置计数新高后若走出"更低低→更高高→更低低"反转结构 = 趋势翻面，剩半仓离场。
5优先级规则2 止损是硬底线（优先），低2 反转是底线之上主动离场不冲突：底线兜底，反转提前下车。
6原测量止盈废弃不再用 2×地板 − 前摆低统一由上面 2R + 跟踪方案取代。
