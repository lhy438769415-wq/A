## 一、先把你的三条规则翻译成"时间线状态机"

设：入场价 `E`、初始止损 `SL0 = 缺口地板`、`R = E − SL0`、固定 2R 线 `T2 = E + 2R`。

```
T0  入场（信号K高点 Buy Stop，次日成交）
     │  全仓 SL = SL0（缺口地板），风险 = R
     │
     ▼
阶段A：等待 2R
     │  若某根 high ≥ T2  →  止盈半仓（剩半仓）
     │                          （此时 2R 也是一次"新高"，见第三节歧义1）
     ▼
阶段B：剩半仓的跟踪
     │  若从未创新高        →  止损维持 SL0（初始地板）
     │  若创造新高（锚点待定）→  移动止损到"回调低点"（规则2，位置待定）
     ▼
阶段C：新高后的反转出场（规则3）
       以"最近一次新高"为基准，计数 LL→HH→LL：
       出现 LL（低于前低）→ 出现 HH（高于前高）→ 出现 LL（低于前低）
       = 反转确认，剩半仓离场。
       期间任何"新高"都会重置这套计数（创新高需重置）。
```

## 二、必须先钉死的三个核心定义

| 定义 | 字面意思 | 歧义点（见第三节） |
|---|---|---|
| **R（初始风险）** | `E − SL0`（缺口地板） | 无歧义，沿用 |
| **固定 2R 线** | `E + 2R` | 无歧义，沿用 |
| **"新高"的锚点** | 价格创造新高点（含盘中） | ⚠️ 相对谁？见歧义1 |
| **"回调低点"** | 入场K（含）前的回调低点 | ⚠️ 是固定 pre-entry 低点，还是随新高抬升？见歧义2 |

## 三、我看到的 4 个歧义 / 冲突点（按重要性排序）

### 歧义1：「新高」相对谁？（最致命）
规则2、规则3 都依赖"价格创造新高"，但**没说相对哪个锚点**。三种可能：

- **(a) 突破腿最高点（Spike High）**：把突破以来最高的那根 high 当作"前高"。只有价格**吃掉突破高点**才算新高。PA 上最站得住——H2 单子要"证明自己"，必须先把突破高点踩在脚下。
- **(b) 入场价 / 信号K高点**：任何高于入场的 high 都算新高。太松——几乎一涨就触发，规则2 形同虚设。
- **(c) 滚动前高**：高于"入场后出现的上一根摆动高"。介于两者之间。

**后果**：若选 (a)，2R 线和"新高"会**解耦**——价格可能先到 2R（半仓止盈）却还没过突破高点（不触发规则2），剩半仓继续扛初始止损，直到后来过突破高点才移动止损。这其实是个**更干净的次序**。若选 (b)，2R 一触发就同时移动止损，跟踪立刻启动。

> 我推荐 **(a)**。下方有数值例子可直观看差异。

### 歧义2：规则2 移动到的"回调低点"是否锁利？（最容易踩坑）
你写的是"**入场K（含）前的回调低点**"——这在字面上 = 信号K（第二次回调 LHLL）的最低价，它**必然低于入场价 E**（因为 E 是信号K的最高价）。

- **若按字面（固定 pre-entry 低点）**：移动后的止损仍在入场价**下方**，意味着即使已经新高、已经止盈半仓，剩半仓**仍可能以亏损离场**，并没有锁住利润。
- **若你想要"锁利"**：应改成「移动到**入场价（保本）**」或「移动到**最近更高的回调低点**」（新高后那次回踩的低点，通常在 E 之上，真正锁利）。

这是规则2 最该想清楚的点。下方我把它做成选择题。

### 歧义3：原"测量止盈目标"（2×地板 − 前摆低）何去何从？
当前回测里有一套 `TP = 2×地板 − 前摆动低`（Al Brooks 等距目标），是全仓的唯一止盈线。你新方案引入了**2R 半仓止盈 + 跟踪出场**，和原测量目标**重叠/冲突**：

- 2R 线（`E+2R`）和测量目标（`2×floor−前摆低`）**通常是两条不同的价**，谁先到？
- 原测量目标现在还用不用？还是整套出场被 2R+跟踪 取代？

我的建议：**废弃原测量目标，统一用"2R 半仓 + 跟踪"方案**，免得两个止盈线打架。但需你确认。

### 歧义4：规则3"低2反转出场" 与 规则2 跟踪止损 谁先谁后？（已分析，基本不冲突）
规则2 移动后的止损（无论固定还是抬升）是**一条硬底线**；规则3 的 LL→HH→LL 是**主动反转出场**。
- 若规则2 移到 pre-entry 低点（歧义2 字面版，远低于 E）：价格在新高后已远离，反转的"最终 LL"一般在更高处就完成，不会先打到那条深底线 → **两者共存，不冲突**，底线只作极端兜底。
- 若规则2 移到最近更高低点（锁利版）：这条线会随新高抬升，可能**压在反转 LL 之上**，那底线会先于"低2"触发——此时需明确：**底线优先，低2 只是没碰到底线时的主动离场**。

→ 这点我建议在 doc 里定为：**规则2 跟踪止损是硬底线（优先），规则3 低2 反转是主动离场（底线之上的提前下车）**。请你确认这个优先级。

## 四、数值例子（让次序变直观）

假设某笔：信号K 高点 `E=10.00`，缺口地板 `SL0=9.00` → `R=1.00`，`2R线 T2=12.00`，突破腿最高点 `SpikeHigh=13.00`。

- **选锚点 (a) 突破高点**：价格先摸到 12.00 → **半仓止盈**（剩半仓 SL 仍=9.00）。之后涨到 13.10，**过突破高点** → 剩半仓止损移到"回调低点"。随后若走 LL→HH→LL → 反转离场。
  → 半仓止盈 与 跟踪启动**分步发生**，逻辑清爽。
- **选锚点 (b) 入场价**：价格刚到 10.01（任何新高）→ 规则2 立刻触发，但此时还没到 2R（12.00）→ 半仓还没止盈、止损却先移了。次序乱。

这例子说明：**锚点选 (a) 比 (b) 次序更自洽**，也是我推荐 (a) 的实操理由。

### 锁定后的精确状态机（实现规格）

设：`E`=入场价（信号K高点 Buy Stop 次日），`SL0`=缺口地板，`R=E−SL0`，`T2=E+2R`，`SH`=突破腿最高点（信号出现前的结构顶点）。

```
T0 入场：全仓 SL = SL0，风险 = R
│
├─ 阶段A 等待2R：
│   任意 post-entry 根 high ≥ T2  →  平半仓（成交于 T2 限价）
│                                 （此时尚未过 SH，故不触发规则2）
│
├─ 阶段B 剩半仓跟踪：
│   若 high 从未 > SH          →  SL 维持 SL0（初始地板）
│   若 high 首次 > SH（盘中）   →  SL 一次性移到「信号K最低价」(固定，不再随新高抬升)
│
└─ 阶段C 新高后反转出场（剩半仓，阶段B触发后生效）：
     以「最近一次新高」为基准计数 LL→HH→LL：
       出现 LL（低于前摆动低）→ 出现 HH（高于前摆动高）→ 出现 LL（低于前摆动低）
       = 反转确认 → 剩半仓离场（成交于最终 LL 低点）
     期间任意 new high → 重置整套计数（创新高需重置）
     优先级：SL(信号K低点) 是硬底线，优先成交；低2 反转是底线之上的主动离场
```

### 回测填充假设（实现时需明确，先按保守默认）
- **2R 半仓成交价**：取 `T2` 限价（high≥T2 即视为触达，按 T2 成交；若跳空越过则按开盘价）。
- **SL 成交价**：按止损价；若次日跳空低开在止损价下方，按开盘价。
- **低2 反转成交价**：按最终 LL 低点；若跳空下破则按开盘价。
- **分仓风险**：半仓已锁定 2R 利润；剩半仓风险 = `E − 当前SL`（移动后为 `E − 信号K低点`）。
