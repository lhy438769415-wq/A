## 1. 回测目标、范围与成功判据

### 1.1 目标
验证**各策略自带的 A+/A/B/C/D 评级是否真的能区分"未来这笔信号赚钱的概率"**。即：评级高的档位，净胜率应显著高于评级低的档位，且在**样本外（后 40% 时间）**依然成立。

### 1.2 范围
- 6 个策略 × 日线/周线 = **9 个批次**：
  - 缺口家族（启用生命周期三过滤）：`structural_gap`（日+周）、`gap_pinbar`（日+周）、`gap_h2`（日+周）
  - 日线专属：`mtr`、`three_k`、`awil`
- 信号来源：各策略 `calculate_signals` 产出 → `compute_rating` 打分 → 统一引擎模拟退出。

### 1.3 成功判据（v2 已修订，区别于 v1）
> v1 的硬门槛"A+ 毛胜率 ≥55%"在"扣费 + 统一模型"下多数策略达不到，且易诱使"放水式 PASS"。v2 改为主判据：

- **主判据 = 评级区分度**：`A+ 测试集净胜率 > 整体净胜率`，且档位基本单调（A+ ≥ A ≥ B ≥ C/D）。
- **辅助判据 = 样本外显著**：A+ 档 Wilson 95% CI 下限应 > 整体基线（或在 CI 内有明显分离）。
- 绝对 55% 作为**参考线**，不再作为硬门槛（边缘策略如 3K 基础率偏低，靠切点放宽）。

> 📌 **评审修订（双门槛并行，D-采纳）**：保留 **55% 净胜率作为"A+ 可操作强推"的硬门槛**（A+ 档测试集净胜率 ≥55% 且 CI 下限 >50% 才对外强推）；**区分度**作为"评级系统整体有效性"判据（A+ ≥ 整体 且档位单调）。两者并行——前者防"达不到就降标准"掩盖评级本身弱，后者防"只看绝对数忽略排序能力"。

## 2. 回测方法论（核心，专业修订 v2）

### 2.1 统一交易模型（跨策略可比的前提）
所有策略共用 `core/backtest_engine.simulate_trade_unified`，仅入场参考价 / 止损 / 目标不同：

| 环节 | 规则 |
|---|---|
| 入场 | 信号后第 1 根起挂 **Buy-Stop**：`max(入场参考价, 开盘) × (1+滑点)`；入场前若直接跌穿止损线 → `INVALIDATED`（撤单，不计入分母） |
| 止损 | 信号自带 `sl_price × (1−滑点)` |
| 目标 | 优先用策略自身 `tp_col`（忠实实盘 R:R）；未显式给则 `入场 + risk_mult×risk`（默认 2R） |
| 最大持仓 | `max_hold` 根到期按收盘平仓 |
| 退出状态 | `WIN` / `LOSS`（入分母）｜`INVALIDATED`/`VOIDED`/`TIMEOUT`（撤单）｜`HOLDING`/`PENDING`（窗口未决/EOF） |

**为什么统一**：v1 各策略退出模型不一致（缺口家族用各自 tp_col、MTR 用 30 根内极值判定），导致跨策略不可比且 MTR 被高估。v2 统一后净胜率/净 EV 可直接横向比较。

### 2.2 Look-ahead（未来函数）安全
评级在 `df.iloc[:idx+1]` **切片**上计算（与实盘信号时刻完全一致，含 `bars_passed=0`）。退出模拟**只使用信号 bar 之后的数据**（`post = df.iloc[idx+1:]`）。这从结构上杜绝了"用未来信息打评级、又用同份数据验评级"的作弊。
> 代价：`time_decay` 因子在回测中恒为 0、不参与校准（仅实盘信号老化有效，聚合时剔除）。已记入方法学注释。

### 2.3 成本模型（真实 A 股口径）⚠️ 与 RATING_PLAN 旧描述不一致
`core/backtest_engine.py` 实测常量：
```
STAMP_SELL_BPS = 5.0    # 印花税 0.05% 仅卖出（2023-08-28 后标准）
COMMISSION_BPS = 3.0    # 佣金 0.03% 双边
SLIPPAGE_BPS  = 0.0     # 滑点 0（信号级基线不含滑点）
# 单边往返约 11bps ≈ 0.11%
```
> 🔴 **与 `docs/RATING_PLAN.md` §5（第 269 行）冲突**：该处仍写"印花税0.1%卖/佣0.025%双边/滑点0.05%"，是**收口前未修正的旧口径**。**以 `core/backtest_engine.py` 代码为唯一真值**（0.05%/0.03%/0）。请在评审时以代码为准，并建议同步修正 RATING_PLAN.md。

### 2.4 缺口家族生命周期三过滤
对缺口家族（`structural_gap` / `gap_pinbar` / `gap_h2`）启用，等待期依次检测：
| 过滤 | 触发 | 状态 | PA 理据 |
|---|---|---|---|
| 缺口回填撤单 | `Low < sl_price`（缺口下沿被击穿） | `INVALIDATED` | 支撑失效 |
| 止盈先达作废 | `High ≥ tp_price`（多头动能已释放） | `VOIDED` | 入场意义消失 |
| 超时失效 | 等待 > 30 根 K | `TIMEOUT` | 久盘动能衰竭 |

撤单**不计入分母**（不污染胜率），对齐既有已验证引擎 `tools/backtest_gap_h2.py` 口径。

### 2.5 训练/测试时间切分（防样本内过拟合）
- 全历史信号按**日期前 60% = TRAIN**（推因子权重），**后 40% = TEST**（验档位）。
- 报告明确区分 **[全样本/内样本]**（仅参考）与 **[测试集/样本外]**（主判据）。
> ✅ **已修复（P0）**：`train_date_cut` 改为逐策略 `agg` 内渲染，报告头显示"切分日见各策略小节"，各策略小节显示真实切分日（如 daily 2024-10-31 / weekly 2025-07-01）。

### 2.6 统计显著性（Wilson 95% CI）
每档附 Wilson 95% 置信区间（`wilson_ci(k,n)`），用于判断 A+ 档是否"显著高于整体基线"还是"被噪声淹没"。

### 2.7 年度 / regime 分层
净胜率按自然年拆分 + CI，检查市况稳定性（见 §4 证据：2025 显著优于其他年）。
> **v2.1 增强**：新增 **regime 牛熊震荡分层**（基于 `YEAR_REGIME` 近似标签，见 harness 常量；可在评审后据具体基准人工校正），报告按 `牛市/熊市/震荡` 分别给净胜率 + CI + net_EV_R，直接回答"edge 是否只在牛市存在"。

### 2.8 逐信号数据集 dump
- 每信号落 `calibration_signals.jsonl`（含 score/letter/factor_hits/status/net_R），分析可复用免重跑（`--analyze-only`）。
> ⚠️ **同日去重已移除（P0）**：原"保留 R:R 最优一笔"逻辑会偏向高 R:R 信号，而 **R:R 本身是评级因子 → 循环偏差**，会系统性污染区分度公正性。信号级评级校准应保留**全部独立信号**（harness 按股逐只处理，不同股票同日信号互不影响；单股单日去重本就无意义）。

### 2.9 PA 合规约束
评级因子严禁引入 `volume` / `relative_vol` / `vol_ma20` / `ADX` / `EMA 斜率` / `均线多头排列`（见 `docs/RATING_PLAN.md` §2.5 黑白名单）。EMA20 仅可作磁力位/Always-In 翻转证据，**不可**作动量打分因子。

### 2.10 与 v1 的 7 处硬伤对比（审计结论，已修复）

| 1 | 零交易成本（毛口径高估） | 统一 A 股成本（2.3） |

## 3. 方法学谱系：4 套既有引擎 + 本校准 harness

本校准 harness 不是凭空新建，而是站在既有 4 套引擎的方法学肩膀上（详见 `docs/backtest_methodology.md`）：

| 引擎 | 定位 | 关键方法学贡献 |
|---|---|---|
| `gap_h2_backtest.py` | 组合级资金回测（单仓 FIFO + 成本） | 成本基线、组合约束、镜像测量目标 `TP=2×GapFloor−PriorSwingLow` |
| `tools/backtest_gap_h2.py` | 信号级纯收益（日+周） | **生命周期三过滤**原型、`INVALIDATED/VOIDED/TIMEOUT` |
| `tools/backtest_struct_gap.py` | 高维 PA 特征 | **EV 概率矩阵**（极品 62.5–68% / 毒性 28–33%）→ 评级切点的实证锚 |
| `tools/research_gap_pinbar_ev.py` | 双止损 EV 研究 | 证实 Pinbar **小止损守 GapFloor（方案 A）EV +0.456R 🥇** 优于宽止损 |
| **`tools/rating_calibration_backtest.py` + `core/backtest_engine.py`（本 harness）** | **评级校准专用** | 统一成本敏感模型 + 训练/测试切分 + Wilson CI + 年度分层 + 逐信号 dump |

**关键经验锚（来自既有引擎，已沉淀为评级切点参考）**：
- struct_gap EV 矩阵：极品（质量>0.8 且连阴<2）= 62.5–68% / +0.45~0.6R；毒性（质量≤0.5 且连阴≥2）= 28–33% / −0.25R。
- pinbar 双止损：方案 A（守 GapFloor）周线 EV +0.456R 🥇。
- 缺口家族 SL=GapFloor，TP=2×GapFloor−PriorSwingLow（已与 `calculate_signals` 输出列一致）。

## 5. Phase 2 收口已完成（代码改动，待评审复核）

### 5.1 gap_h2 倒挂根因修正（重要纠正）
复核 `train_factor_weights` 的 `w` 语义（= sign(命中组净胜率−未中组)）后，发现历史摘要"翻转缺口宽度%/回调速度符号"是**误记**：
- 缺口宽度% `w=+0.51`、回调速度 `w=+0.67` → 命中组胜率都更高，**方向本就正确，不翻**。
- **真正倒挂根因是"两腿对称性"** `w=−0.8`（命中 34.7% vs 未中 42.7%，δ≈8 点，显著）。已翻转：`compute_rating` 中 `leg2_shallow` 时权重 `+1 → −1`（hit 仍记 `leg2_shallow`，与回测 `factor_hits` 口径一致）。
> 复跑后预期：D 档将失去"浅二腿"加分，倒挂应消失。

### 5.2 AWIL 重设计（消除恒为 A+ 退化）
原 `compute_rating` 含 4 个**恒定因子**（收盘位置/全程站上EMA20/空头失败次数/RR，皆因策略前置条件恒为正）→ 520 信号全判 A+ 无区分。改为 6 个**随信号变化**的纯 PA 因子：实体占比 / 回调速度（新增 `awil_pb_bars` 列）/ EMA20 磁力距离 / 回撤深度比 / 两腿对称性 / 下影陷阱。已验证三变体产出 `A / B / D`，不再全 A+。

### 5.3 修复既有 bug
`structural_gap_strategy.py` 漏 `from typing import Optional`，导致 `test_rating.py` 收集即 `NameError`——与本次改动无关，最小补 import。

### 5.4 验证结果
- `tests/test_rating.py` **10/10 passed**（band 契约未破）。
- 临时构造校验：gap_h2 对称性翻转生效；awil 不再全 A+。
- 质量门禁：本次改动 3 文件**无新增红线**；33 处 `sys.path.insert` 全是 `tools/`、`hunter.py` 等的既有债务（P8），非本次引入。

## 8. 已知局限与风险（汇总）

1. **A+ 样本极小**（多数 n<50），CI 宽，统计显著性不足——"高置信推送"主张的最薄弱点。
2. **强 regime 依赖**（2025 牛市驱动多数 edge），熊/震荡市多数策略盈亏平衡或为负，前向不可盲信。
3. **统一 2R + Buy-Stop 模型**可能与某些策略"原生意图"不完全一致（已尽量用 `tp_col` 忠实 R:R）。
4. **Look-ahead 设计**使 `time_decay` 因子在回测恒 0，该因子实际仅实盘有效。
5. **mtr 样本量巨大（85,704 已结案）但 A+ 仅 50**，主体 A/B ≈ 48% 抛硬币——mtr 评级需重新审视是否真有区分力。
6. **报告头"切分日=-"显示 bug**（读错层级），不影响计算，建议顺手修。
