# GAP H2 出场方案对比：2R全止盈(简化) vs 阶段式新出场 vs 旧出场

> 数据：本地 `baostock.db` 日线全历史。信号生成：复用 `GapH2Strategy`（C0 原版）与 `GapH2EnhancedStrategy`（C0+重置，真缺口/新高重置/地板/40-2）。  
> 旧出场 `evaluate_trade`：全仓 TP=测量目标(2×地板−前摆低) / SL=地板。  
> 阶段式新出场 `evaluate_trade_new_exit`：阶段A 2R半仓止盈 → 阶段B 过突破高点 SH 移止损到信号K低点 → 阶段C LL→HH→LL 反转出场。  
> **简化新出场 `evaluate_trade_2r_all`**：整仓，到 2R 全止盈、破地板全止损，无跟踪/反转。固定 2:1 盈亏比。

## 三、结论

- **B'(2R全止盈) vs B(阶段式)**：同为 C0 信号，简化后 EV 提升 （+0.0970 vs +0.0960）；胜率 36.3% vs 43.1%；平均盈R 2.050(封顶≈2R) vs 1.296。
- **D'(2R全止盈) vs D(阶段式)**：同为 C0+重置 信号，简化后 EV 提升 （+0.0914 vs +0.0839）；胜率 36.1% vs 44.1%。
- **对比 A(旧出场)**：B' EV = +0.0970（劣于 A 的 +0.1256）；D' EV = +0.0914（劣于 A）。
- 含义：2R全止盈把每笔盈利封顶在≈2R，亏损固定≈1R（地板），结构上是纯 2:1 目标单；与阶段式新出场比，少了「让利润奔跑」(跟踪/反转) 的部分，也少了「移损到信号K低点减亏」的部分。

## 四、口径说明（动态入场改造后）

> 本表为 **H2 动态入场改造后** 的回测：入场不再死钉信号K高点，而是由回测脚本自调 `_apply_dynamic_entry` 跟踪扫描——从信号K后只要**没出现高点抬升(HH)**，挂单就顺回调下移到该K高点（**含内包K**，Al Brooks：回调=趋势中任何暂停）；直到出现 HH 才收口成交；破地板 / 测量目标先达 / 超时(30bar) 则信号作废。
> 判据演变：本轮由「高低点都降(LHLL)才下移」改为「**只看高点(HH)，内包K也下移**」。改造效应：约 31% 的「回调后不再创新高」失败信号被取消，信号基数由原 3629(A/B/B') / 2344(D/D') 降至 **2530(A/B/B') / 1662(D/D')**。取消的多为失败信号，故 B'/D' 的 EV 较改造前抬升。
> 入场定点：回测脚本自算动态入场，读收口成交K仅在指定K成交，等待期不提前触发（避免用最终下移价在阴跌K误进场）。
