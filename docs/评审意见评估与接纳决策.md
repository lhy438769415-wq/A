## 2. 对评审本身的补充纠正（评审未发现 / 表述需纠）

### 盲区 a（重大）：日线数据深度使"全历史日线回测"前提不成立
评审在 D4 仅说"需验证 DB 深度"并怀疑 8000 可行性，**未断言结论**。我实测确认：

- **`daily_bars` 范围 `2023-01-03 ~ 2026-07-24`，每支股最多 861 根** → 本地根本不存在 2023 之前的日线。
- 因此：我方原计划"明天跑全历史日线（--limit 8000）"**既参数错（`--limit` 是股票数非 K 线数），又目标错（无更多日线可跑）**。
- **已完成的 2023 回测对日线而言 = 本地日线全量**，日线无需再跑。
- **真实的"全历史"在周线**：`weekly_bars` 范围 `2011-03-04 ~ 2026-07-24`（787 根/股，15 年），覆盖 2015 股灾 / 2018 熊 / 2019–2021 牛 / 2022 熊 / 2023–2025 → **这才是真正跨牛熊的多周期验证**。

> 修正后的 P1 计划：**日线不再单独回测；weekly 三策略（structural_weekly / gap_pinbar_weekly / gap_h2_weekly）去掉 `--start-date` 跑全 2011–2026。**

### 盲区 b：评审 §1.5 表述不准（但结论正确）
评审写"同日两个不同股票的 A+ 和 C 信号去重"——实际 harness 按股逐只跑，`by_date` 仅在该股内部按日分组，**不同股票不会互删**。但"去掉同日去重"的结论仍正确，修正后的理由更准确：**保留"最优 R:R"会偏向高 R:R 信号，而 RR 是评级因子 → 循环偏差**，故信号级校准应全保留。

### 盲区 c：评审未指出 2023 回测 weekly 仅覆盖 2023–2026
若当初以 `--start-date 2023` 运行，weekly 只用了 2011–2026 中的近 3 年段，未触达 2011–2022 的历史 regime。真正的多周期验证恰在 weekly 全历史（盲区 a 已覆盖）。
