## 六、结论

### 任务1：C0+重置 信号 + 新出场（D）几何？
- D（新出场）：EV = +0.0856 R/单，胜率 44.5%，已结案 1621 笔，累计净R +138.7，最大回撤 -174.74。
- C（同基底+旧出场）：EV = +0.1318 R/单，胜率 35.7%，累计净R +213.3。
- 结论：在 C0+重置 基底上，**新出场相对旧出场 EV 下降 （ΔEV = -0.0462）；信号数 D=1628 / C=1628。

### 任务2：C0 原版信号 + 新出场（B）是否比 C0 原版+旧出场（A）EV 更好？
- A（C0+旧出场，生产基线）：EV = +0.1169 R/单，胜率 37.8%，累计净R +288.8。
- B（C0+新出场）：EV = +0.0897 R/单，胜率 43.2%，累计净R +221.9。
- 结论：C0 原版信号套用新出场后，EV **下降** （ΔEV = -0.0272）；胜率 A=37.8% → B=43.2%；结案样本 A=2470 / B=2473（新出场 HOLDING 未结 11 笔被排除）。

### 注意事项 / 方法口径
- **前过滤一致**：新旧出场均保留「缺口回填撤单 / 测量目标先达作废 / 30bar 超时」，故 A↔B、C↔D 的差异仅来自**出场机械**（全仓TP/SL vs 2R半仓+跟踪+反转）。
- **测量目标**：新出场不再以 `2×地板−前摆低` 作为出场线（已废弃），但仍作为「入场前先达即作废」的 setup 过滤，避免把已跑完的行情误当作信号。
- **HOLDING 处理**：EOF（数据末尾）仍未结的单子记为 HOLDING 并排除出 EV（与原框架一致）；新出场在「未过 SH 且未达 2R」时缺乏主动出场，HOLDING 占比偏高属设计特征，已单列披露。
- **SH（突破腿最高点）**：取突破组内信号K之前的最高 high。
- **阶段C 反转口径**：以「最近新高」为基准，跌破「前次回踩低点」即判 LL→HH→LL 反转确认（新高重置计数）；信号K低点止损为硬底线，优先成交。
- **R 口径**：以 actual_entry（Buy Stop 实际成交=max(信号K高点, 开盘)）与 SL0（地板）之差为初始 R；移动止损后剩余仓位风险随之变化，total_r 统一折合为「初始整仓 R」。
